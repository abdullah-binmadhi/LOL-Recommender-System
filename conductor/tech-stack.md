# Technology Stack

## Frontend
- **HTML5:** Semantic markup for the structure of the recommender system.
- **CSS3:** Vanilla CSS for styling, focusing on a clean, modern, and responsive design.
- **JavaScript (ES6+):** Vanilla JavaScript for application logic, DOM manipulation, and the implementation of the core recommendation algorithms.

## Machine Learning & Logic
- **Custom ML Implementations:** Client-side JavaScript implementations of:
    - **Random Forest**
    - **Decision Tree**
    - **K-Nearest Neighbors (KNN)**
- **Ensemble Logic:** Weighted voting system to aggregate algorithm outputs for final recommendations.

## Data & Storage
- **JSON:** Local storage format for champion attributes, questions, guides, and tips.
- **Static Assets:** Optimized images and JSON files served directly.

## Tooling & Analysis
- **Python:** Used for data preprocessing, champion analysis, and generating performance visualization reports (using libraries like Matplotlib or Seaborn).

## Deployment & Hosting
- **GitHub Pages:** Static site hosting for the live demonstration.
- **Vercel:** Configuration present for alternative or advanced deployment scenarios.
