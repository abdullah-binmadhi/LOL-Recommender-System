# League of Legends Champion Recommender

## Initial Concept
The project is an AI-powered champion recommendation system that uses ensemble machine learning (Random Forest, Decision Tree, and K-Nearest Neighbors) to suggest League of Legends champions based on a user's gameplay preferences and psychological profile.

## Target Users
- **New Players:** Individuals looking to find their first main champions through guided analysis.
- **Experienced Players:** Veterans wanting to expand their champion pool based on their specific playstyle tendencies.
- **Competitive Players:** Data-driven players seeking objective insights into which champions best align with their mechanical and strategic strengths.

## Primary Goals
- **High Accuracy:** Deliver personalized and precise champion recommendations using an ensemble ML approach.
- **Transparency & Education:** Help users understand the logic behind recommendations through clear scoring breakdowns of each algorithm.
- **Promote Diversity:** Encourage players to explore a varied champion pool by ensuring recommendations span different roles and mechanics.

## Key Features
- **10-Question Comprehensive Profiler:** A balanced assessment of gameplay mechanics and psychological traits.
- **Visual Algorithmic Breakdown:** Detailed visibility into how Random Forest, Decision Tree, and KNN each contributed to the final score.
- **Advanced Result Filtering:** Capabilities to refine suggestions by role, difficulty level, or champion ownership.

## User Experience (UX)
- **High Performance:** A fast, lightning-quick responsive single-page application experience.
- **Data-Driven Visualizations:** Clear, intuitive charts and bars that explain the "why" behind every suggestion.
- **Modern Minimalism:** A clean UI design that prioritizes clarity and avoids data overwhelm.

## Future Vision
- **Riot API Integration:** Incorporate real-time match history and performance data for even deeper personalization.
- **Model Refinement:** Continuously improve the ensemble voting system by training on larger, more diverse datasets.
